# Misc API {#misc-api}

Miscellaneous utility functions.

### `ntop.getDirs()` {#ntop-getdirs}

Get ntopng directory information.

**Returns**: table (installdir, workingdir, scriptdir, httpdocsdir, callbacksdir).

### `ntop.getInfo()` {#ntop-getinfo}

Get ntopng status information.

**Returns**: ntopng information.

### `ntop.getUptime()` {#ntop-getuptime}

Get seconds from ntopng startup.

**Returns**: ntopng uptime in seconds.

### `ntop.getHttpPrefix()` {#ntop-gethttpprefix}

Get the ntopng HTTP prefix.

@details The HTTP prefix is the initial part of the ntopng URL, which consists of HTTP host, port and optionally a user-defined prefix. Any URL within ntopng should include this prefix.

**Returns**: the HTTP prefix.

### `ntop.getRandomCSRFValue()` {#ntop-getrandomcsrfvalue}

Generate a random value to prevent CSRF and XSRF attacks.

**Returns**: the token value.

::: info
Any HTTP POST request must contain a "csrf" field with a token value generated by a call to this function.
:::

### `ntop.isShuttingDown()` {#ntop-isshuttingdown}

Check if ntopng is shuttind down.

**Returns**: true if is shutting down, false otherwise.

### `ntop.getLocalNetworks()` {#ntop-getlocalnetworks}

Get the ntopng local networks list.

**Returns**: table (network_address -> "").

### `ntop.addLocalNetwork(string network_cidr)` {#ntop-addlocalnetwork}

Add a network to the ntopng local networks list.

**Parameters**

- `network_cidr`: the network to add in CIDR format.

### `ntop.setMacDeviceType(string mac, int device_type, bool overwrite)` {#ntop-setmacdevicetype}

Set L2 device type.

**Parameters**

- `mac`: device MAC address
- `device_type`: the device type id to set.
- `overwrite`: if true, the existing device type, if any, will be overwritten.

### `interface.reloadHostPools()` {#interface-reloadhostpools}

Reload Host Pool membership information after changes from Lua.

### `ntop.getNetworkNameById(int network_id)` {#ntop-getnetworknamebyid}

Retrieves a ntopng local network by its id.

**Parameters**

- `network_id`: the local network id.

**Returns**: the network address on success, an empty string otherwise.

### `ntop.getNetworkIdByName(string network_cidr)` {#ntop-getnetworkidbyname}

Retrieves a ntopng local network id by its name.

**Parameters**

- `network_cidr`: the local network cidr.

**Returns**: the network id on success, -1 otherwise.

### `ntop.getHostInformation()` {#ntop-gethostinformation}

Get information about the currest host.

**Returns**: table (ip, instance_name).

### `ntop.systemHostStat()` {#ntop-systemhoststat}

Get ntopng host statistics.

**Returns**: table (cpu_load, cpu_idle, mem_total, mem_free, mem_buffers, mem_cached, mem_shmem. mem_used).

### `ntop.syslog(string message, int syslog_severity)` {#ntop-syslog}

Send a message to syslog.

**Parameters**

- `message`: the message to send.
- `syslog_severity`: an integer representing the standard syslog severity as per RFC 5424. LOG_INFO is used when severity is not specified.

### `ntop.setLoggingLevel(string level)` {#ntop-setlogginglevel}

Set ntopng logging level.

**Parameters**

- `level`: one of "trace", "debug", "info", "normal", "warning", "error".

### `ntop.traceEvent(string msg)` {#ntop-traceevent}

Log a message.

**Parameters**

- `msg`: the message to log.

::: info
Message will be logged with "normal" level.
:::

### `ntop.verboseTrace()` {#ntop-verbosetrace}

Check if verbose trace is enabled.

**Returns**: true if verborse trace is enabled, false otherwise.

### `ntop.gettimemsec()` {#ntop-gettimemsec}

Get the current time in milliseconds.

**Returns**: the current milliseconds time.

### `ntop.getticks()` {#ntop-getticks}

Get the current CPU ticks.

**Returns**: the current CPU ticks.

### `ntop.gettickspersec()` {#ntop-gettickspersec}

Get the CPU ticks per second.

**Returns**: the CPU ticks per second.

::: info
this can be used with ntop.getticks() deltas to calculate time spent.
:::

### `ntop.isLoginDisabled()` {#ntop-islogindisabled}

Check if the ntopng GUI login is disable.

**Returns**: true if login is disabled, false otherwise.

### `ntop.hasVLANs()` {#ntop-hasvlans}

Check if ntopng has seen any VLAN tagged traffic.

**Returns**: true if VLAN traffic has been seen, false otherwise.

### `ntop.hasGeoIP()` {#ntop-hasgeoip}

Check if ntopng has Geo IP support available.

**Returns**: true if Geo IP is available, false otherwise.

### `ntop.isWindows()` {#ntop-iswindows}

Check if the operating system is Windows.

**Returns**: true if Windows, false otherwise.

### `ntop.msleep(int duration)` {#ntop-msleep}

Sleep with milliseconds accuracy.

**Parameters**

- `duration`: in milliseconds.

### `ntop.getMacManufacturer(string mac)` {#ntop-getmacmanufacturer}

Get the manufacturer name from mac address.

**Parameters**

- `mac`: the MAC address.

**Returns**: table(short, extended) on success, nil otherwise.

### `ntop.md5(string s)` {#ntop-md5}

Compute the MD5 of the provided string.

**Parameters**

- `s`: the string to hash

**Returns**: the computed string MD5.

### `ntop.exec_sql_query(string query)` {#ntop-exec-sql-query}

Execute a historical query and get the result

**Parameters**

- `query`: the query to execute

**Returns**: the query result

::: info
This only works when ntopng is configured with "-F=clickhouse"
:::

### `ntop.resetStats()` {#ntop-resetstats}

Resets multiple stats in ntopng, which include the hosts and mac traffic counters.

::: info
This is the function called when "Midnight Stats Reset" is enabled from the GUI.
:::

### `ntop.isPro()` {#ntop-ispro}

Check if ntopng has the pro features.

**Returns**: true if the pro features are available, false otherwise.

### `ntop.isEnterpriseM()` {#ntop-isenterprisem}

Check if ntopng has the Enterprise M features.

**Returns**: true if the Enterprise M features are available, false otherwise.

### `ntop.isEnterpriseL()` {#ntop-isenterprisel}

Check if ntopng has the Enterprise L features.

**Returns**: true if the Enterprise L features are available, false otherwise.

### `ntop.isPackage()` {#ntop-ispackage}

Check if ntopng is running as a systemd service.

**Returns**: true if running as service, false otherwise.

### `ntop.getStartupEpoch()` {#ntop-getstartupepoch}

Get the startup Unix epoch of ntopng

**Returns**: the startup epoch

### `ntop.serviceRestart()` {#ntop-servicerestart}

Restart ntopng (when running as a service)

::: info
This only works when ntop.isPackage() returns true
:::

### `ntop.matchCustomCategory(string host)` {#ntop-matchcustomcategory}

Match the given host into an nDPI category.

**Parameters**

- `host`: the host to match

**Returns**: value the nDPI category ID on success, nil otherwise.

### `ntop.getTLSVersionName(int tls_version)` {#ntop-gettlsversionname}

Converts a TLS version ID to the corresponding TLS version name.

**Parameters**

- `tls_version`: the TLS version ID

**Returns**: the TLS version name

### `ntop.bitmapIsSet(int bitmap, int bit)` {#ntop-bitmapisset}

Check if the given bit is set into the bitmap

**Parameters**

- `bitmap`: the numeric bitmap
- `bit`: the bit index to check

**Returns**: true if the bit is set, false otherwise

### `ntop.bitmapSet(int bitmap, int bit)` {#ntop-bitmapset}

Set a bit into the bitmap

**Parameters**

- `bitmap`: the numeric bitmap
- `bit`: the bit index to set

**Returns**: true if the bitmap has changed, false otherwise

### `ntop.bitmapClear(int bitmap, int bit)` {#ntop-bitmapclear}

Clear a bit into the bitmap

**Parameters**

- `bitmap`: the numeric bitmap
- `bit`: the bit index to clear

**Returns**: true if the bitmap has changed, false otherwise

### `ntop.setnDPIProtoCategory(int proto, int category)` {#ntop-setndpiprotocategory}

Associate the protocol to the specified nDPI category

**Parameters**

- `proto`: the protocol id
- `category`: the category id

### `ntop.getnDPIProtoCategory(int proto)` {#ntop-getndpiprotocategory}

Get the nDPI category currently associated to the protocol

**Parameters**

- `proto`: the protocol id to query the category for

**Returns**: a table (id->category_id, name->category_name) on success, nil otherwise.

::: info
the protocol to category mapping can be changed dynamically via *setnDPICategory*
:::

### `ntop.ptreeClear()` {#ntop-ptreeclear}

Initialize an empty patricia tree into this vm

### `ntop.ptreeInsert(string addr, uint16_t value)` {#ntop-ptreeinsert}

Insert an address into the vm patricia tree

**Parameters**

- `addr`: the address to insert
- `value`: a numeric value to associate to the node (except 65535)

**Returns**: true on success, false otherwise

### `ntop.ptreeMatch(string addr)` {#ntop-ptreematch}

Match a given address with the vm patricia tree

**Parameters**

- `addr`: the address to match

**Returns**: the numeric value associated with the node on success, nil otherwise

### `ntop.isDeadlineApproaching()` {#ntop-isdeadlineapproaching}

Check if the current periodic script deadline is near

**Returns**: true if the deadline is approaching, false otherwise

::: info
this can be used by a periodic script to detect if it should hurry up to finish its work
:::

### `ntop.getDeadline()` {#ntop-getdeadline}

Get the current periodic script deadline.

**Returns**: the periodic script deadline on success, 0 otherwise

### `ntop.speedtest()` {#ntop-speedtest}

Check Internet speed using speedtest.net services

**Returns**: JSON that includes the speedtest report, or NULL in case of error
