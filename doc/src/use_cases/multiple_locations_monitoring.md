# Monitoring Multiple Locations {#monitoring-multiple-locations}

To monitor data from multiple locations, even geographically distributed, refer to [Using ntopng with nProbe](/using_with_other_tools/nprobe.md#usingntopngwithnprobe) and to [Monitoring Multiple Locations](https://www.ntop.org/nprobe/network-monitoring-101-a-beginners-guide-to-understanding-ntop-tools/). Dealing with public networks and firewalls is explained in blog post post [Best Practices for the Collection of Flows with ntopng and nProbe](https://www.ntop.org/nprobe/best-practices-for-the-collection-of-flows-with-ntopng-and-nprobe/).

::: info
An nProbe license is required for each location.
:::
