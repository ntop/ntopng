# Suricata {#suricata}

ntopng integrates with the Intrusion Detection System (IDS) Suricata to augment the traffic with security metadata (see [Suricata Integration](/third_party_integrations/suricata.md#suricata-integration)). Blog post [ntopng & Suricata: Unifying Visibility with Security](https://www.ntop.org/ntopng/ntopng-suricata-unifying-visibility-with-security/) explains this in detail.
