# Mikrotik {#mikrotik}

ntopng features Mikrotik traffic monitoring. To monitor Mikrotik traffic, ntopng needs to be used in combination with nProbe (see [Using ntopng with nProbe](/using_with_other_tools/nprobe.md#usingntopngwithnprobe)). A blog post [How to Analyse MikroTik Traffic Using ntopng](https://www.ntop.org/ntopng/how-to-analyse-mikrotik-traffic-using-ntopng/) explains how to properly configure the Mikrotik, nProbe and ntopng for this purpose.

::: info
An nProbe license is required.
:::
