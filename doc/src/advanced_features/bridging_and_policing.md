# Bridging and Traffic Policing {#bridging-and-traffic-policing}

ntopng allows the users to monitor the network traffic, providing visibility.
The ability to also *enforce Traffic Policies* is available in:

- [nEdge] - an extended ntopng version that can run inline, check out the [nEdge documentation] for more details.
- [nFW](https://www.ntop.org/guides/nFW/) - ntopng can be used to configure policies for nFW as explained in [Host Pools section].
